# My Portfolio

This project is a personal portfolio website for Veendy Suseno, an IT Support Specialist and Network Support professional. The site showcases experience, technical skills, projects, education, and contact information in a clean single-page layout.

## Overview

- Professional profile and intro section
- Technical skill and tools overview
- Featured project highlights
- Experience and education timeline
- Contact form and social links
- Downloadable CV button

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Project Structure

- `index.html` — main page structure
- `style.css` — visual design and responsive layout
- `script.js` — content data and rendering logic
- `assets/` — images and CV assets

## How to Run

Because this is a static website, you can open it directly in a browser:

1. Open `index.html` in your browser, or
2. Run a local web server from the project folder:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Customization

You can update personal information, social links, skills, project details, and CV URL in `script.js` within the `DATA` object.
