## How to Run

This is a static website, so it can be opened directly in a web browser.

### Option 1 — Open Directly

Open:

```text
index.html
```

in your preferred web browser.

### Option 2 — Run with Python

Open a terminal in the project directory and run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Customization

Personal information, skills, projects, education, experience, social links, and other portfolio content can be customized through the `DATA` object in:

```text
script.js
```

Website styling and responsive behavior can be modified in:

```text
style.css
```
